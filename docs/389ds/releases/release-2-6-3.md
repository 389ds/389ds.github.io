389 Directory Server 2.6.3
--------------------------

The 389 Directory Server team is proud to announce 389-ds-base version 2.6.3.

The new package and version is:

- 389-ds-base-2.6.3

Source tarball: [GitHub Releases](https://github.com/389ds/389-ds-base/releases/tag/389-ds-base-2.6.3)

### Highlights in 2.6.3

- Security fixes for [CVE-2025-14905](https://access.redhat.com/security/cve/CVE-2025-14905), [CVE-2026-11770](https://access.redhat.com/security/cve/CVE-2026-11770), [CVE-2026-18355](https://access.redhat.com/security/cve/CVE-2026-18355), [CVE-2026-18453](https://access.redhat.com/security/cve/CVE-2026-18453), [CVE-2026-18922](https://access.redhat.com/security/cve/CVE-2026-18922), [CVE-2026-19843](https://access.redhat.com/security/cve/CVE-2026-19843), [CVE-2026-76560](https://access.redhat.com/security/cve/CVE-2026-76560), [CVE-2026-9064](https://access.redhat.com/security/cve/CVE-2026-9064).
- Fix deferred MemberOf updates, replication-agreement validation, LMDB index updates, and replication total initialization.
- Prevent crashes and data loss during online reindex, large subtree rename, and retro changelog processing.
- Improve replication log analysis, WebUI group management, password policy controls, and index-repair tooling.

See [Download](https://www.port389.org/docs/389ds/download.html) for package installation and [Install Guide](https://www.port389.org/docs/389ds/howto/howto-install-389.html) for setup.
