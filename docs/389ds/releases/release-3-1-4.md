389 Directory Server 3.1.4
--------------------------

The 389 Directory Server team is proud to announce 389-ds-base version 3.1.4.

- 389-ds-base-3.1.4

Source tarball: [GitHub Releases](https://github.com/389ds/389-ds-base/releases/tag/389-ds-base-3.1.4)

### Highlights in 3.1.4

- Add dynamic lists, dynamic certificate search support, and replication log analysis sampling.
- Improve DNA replication locking, paged-search locking, and MemberOf behavior.
- Fix entry-cache eviction failures, BDB-to-LMDB conversion crashes, alias plugin memory corruption, and online initialization.

See [Download](https://www.port389.org/docs/389ds/download.html) for package installation and [Install Guide](https://www.port389.org/docs/389ds/howto/howto-install-389.html) for setup.
